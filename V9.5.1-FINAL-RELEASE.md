# Hamsa Nabd V9.5.2 — Final Patch Release

This patch fixes three verified issues in V9.5.0:

1. Removed the legacy `name` field from `twilight.json`; retained the canonical `theme_name`, `repo_url`, and `version` fields.
2. Removed 18 suspicious `common.*` translation calls and moved them to the theme-owned `hn.*` namespace. The remaining `common.*` calls are limited to keys verified against Salla's official Raed theme source: `back_home`, `email`, `mobile`, and `tax_number`.
3. Removed the duplicate manual checkout button from `pages/cart.twig`. The page now relies on `salla-cart-summary-card` for the cart summary/checkout UI and no longer registers the obsolete `data-hn-cart-submit` handler.

Version: 9.5.2
