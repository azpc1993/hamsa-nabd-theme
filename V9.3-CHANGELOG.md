# Hamsa Nabd V9.3.0

## Smart Commerce Pack
- Gift Finder 2.0: recipient + occasion + budget matching with configurable recommendation reasons.
- Smart Box 2.0: configurable box, contents, and optional extras with interactive selection summary.
- Smart Bundle: configurable bundle cards with contents, discount, price, and CTA.
- Smart Campaign: upgraded campaign countdown with badge, promo code, message, background image, and urgency presentation.
- Recommendations 2.0: configurable recommendation tabs and reasons per product.

- Preserves all 30 required Salla components from the previous release.
- No undocumented Salla API is required by the new V9.3 interactions.
- Client-side interactions are progressive enhancements; native Salla functionality remains intact.
- RTL and mobile responsive styles included.
