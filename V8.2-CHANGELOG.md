# Hamsa Nabd 8.2.0

## Functional commerce upgrades
- Replaced the header search wiring with Salla's native `salla-search` component.
- Replaced the legacy wishlist counter with `salla-wishlist-summary`.
- Added native quick-buy support on eligible simple products.
- Added native installment block on product pages.
- Added native gifting support on eligible products.
- Added native social sharing.
- Added native product metadata and reviews summary.
- Added native product offers block.
- Kept Salla's native add-to-cart/options/quantity/fast-checkout path.
- Removed inline event handlers from Twig and delegated cart/size-guide actions to the theme JS layer.
- Removed silent JavaScript placeholders from the build pipeline; required page assets now fail the build if missing.
- Added real source files for home/category/product page assets.
- Added product-page settings for merchant control over the new commerce features.
- Preserved the existing Twilight/Salla component architecture rather than replacing it with mock APIs.

## Validation
- `npm run production` passes.
- Node syntax checks pass for all theme JS files.
- Theme JSON files parse successfully.
- Twig inline event-handler scan returns no matches.

## Platform note
Twilight injects the current Salla JS SDK and native web components into themes. The new integrations intentionally use those native components so cart, search, wishlist, quick-buy, gifting, installments, offers and reviews remain compatible with Salla's platform services.
