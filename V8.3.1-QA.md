# Hamsa Nabd 8.3.1 QA

## Scope
Static/build QA for the V8.3.1 source package. Live Salla Preview/checkout still requires a Salla merchant/Partners Portal environment.

## Checks
- twilight.json parses as JSON and exposes documented metadata keys: version/theme_name/repo_url/support_url.
- package.json parses.
- Arabic and English locale keys referenced by `trans()` are present.
- No inline onclick/onchange/onsubmit handlers in source templates.
- JavaScript syntax check passes for source page scripts.
- Production build completes.
- Public assets are regenerated from source.
- Rich HTML fields retain `raw` only where Salla content is expected to contain formatted HTML.

## Live-only checks
- Theme Preview rendering
- Product option combinations and required options
- Quick Buy/Quick Order
- Gifting and installment availability
- Wishlist/account authentication
- Cart/checkout/payment methods
- Orders, shipments, loyalty, thank-you flow
