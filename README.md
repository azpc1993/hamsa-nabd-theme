# ثيم همسة نبض — Hamsa Nabd ✦ (الإصدار 11)

ثيم لمنصة **سلة** بهوية **الكحلي والذهبي** لمتاجر الرياضة والأزياء والهدايا.
الإصدار 11 أُعيد بناؤه بالكامل على **محرك ثيم شيماء**: صفحات كاملة (المنتج، السلة، الطلبات، الحساب، الولاء، المدونة…)، نظام بناء Webpack + Tailwind، ونظام خيارات موحّد لكل العناصر — مع الحفاظ على كل عناصر وإعدادات همسة نبض السابقة بنفس المعرّفات.

## المحتويات
- **30 عنصراً من همسة نبض** بنفس المسارات والحقول (`home.hero-banner` … `home.compare-products`)، وصار كل عنصر يدعم إعدادات القسم: الخلفية، المسافة، الإظهار على الكمبيوتر/الجوال.
- **10 عناصر من محرك شيماء** مرتبطة ببيانات المتجر: دوائر التصنيفات، شريط النصوص المتحرك، بانرات العروض، تبويبات المنتجات، منتجات تصنيف، عرض بعداد تنازلي، كوبون، اشترِ أكثر ووفّر أكثر، قصة المتجر، انضم لقنواتنا.
- **6 عناصر محسّنة** من القاعدة: صور متحركة، روابط سريعة، منتجات مع خلفية، صور مربعة، الماركات، آراء العملاء.
- **95 إعداداً** للثيم: كل إعدادات همسة نبض (بنفس المعرّفات) + إعدادات الهوية والبطاقات والنافذة الترحيبية والشريط العلوي.

## صور المعاينة
في مجلد `previews/` (WebP خفيفة، خارج `public/` فلا تزيد حجم الثيم)، وروابطها في `twilight.json`:
`https://cdn.jsdelivr.net/gh/azpc1993/hamsa-nabd-theme@main/previews/<العنصر>.webp`
إذا كان فرع المستودع غير `main` عدّل الروابط.

## التطوير
```bash
pnpm install
pnpm run production   # يبني public/
```
