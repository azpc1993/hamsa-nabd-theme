# ثيم همسة نبض 9.5.0 — Salla Twilight

الإصدار المطوّر والمجهز للرفع إلى مستودع GitHub المرتبط مع Salla Partners Portal.

## ما الجديد في 9.5.0
- معاينات المكونات تستخدم روابط عامة قابلة للتحميل بدل المسارات المحلية.
- 30 مكونًا مخصصًا مع أمثلة وحقول إرشادية.
- 42 إعدادًا عامًا للثيم تشمل الهيدر، التنقل، التصميم، البطاقات، صفحات الأقسام، صفحة المنتج، الفوتر والأداء.
- إعدادات إضافية داخل المكونات الرئيسية.
- أبعاد صور مضافة لحقول الصور عندما تكون معروفة.
- المكونات الأساسية مهيأة للظهور في تجربة المعاينة الأولى.
- الحفاظ على Twilight features وSalla web components وhooks.
- إعدادات فعلية وليست مجرد خيارات غير مستخدمة.

## بنية المستودع

`twilight.json` موجود في الجذر، مع `src/` و`public/` و`scripts/`.

## المعاينات

تستخدم المعاينات صورًا من المستودع نفسه عبر:
`https://raw.githubusercontent.com/azpc1993/hamsa-nabd-theme/main/src/assets/images/`

إذا كان فرع GitHub مختلفًا عن `main`، يجب تعديل الروابط في `twilight.json`.

## الفحص

تم تشغيل build المحلي بنجاح، وفحص JSON وJavaScript. الاختبار النهائي داخل Partners Portal ضروري للتحقق من سلوك المحرر الفعلي وإضافة/حذف/ترتيب المكونات.
