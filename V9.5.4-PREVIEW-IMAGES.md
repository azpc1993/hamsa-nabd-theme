# Hamsa Nabd V9.5.4 — Native Component Preview Images

- 30 component preview PNGs are stored under `src/assets/images/component-previews/`.
- Each component in `twilight.json` points to its matching preview image.
- The preview compositions follow the actual Hamsa Nabd V9.5.3 UI identity: navy, gold, ivory, rounded cards, buttons, spacing, product-card treatment and responsive patterns.
- Store visual material used in the preview compositions is sourced from the provided Hamsa Nabd store showcase screenshot; no Raed preview artwork is used in these component previews.
- The red annotation marks from the supplied screenshot were removed before cropping the store visual material.
- The preview image URLs use the public GitHub repository path so the Partners Portal can request the image files after repository sync.

## Important portal check

After syncing the repository in Salla Partners Portal, verify that the component gallery and each component editor load the corresponding image. If the portal still blocks the repository-hosted image URL, the same PNG files should be uploaded to a Salla-hosted media/CDN location and the URLs in `twilight.json` replaced with those Salla CDN URLs.
